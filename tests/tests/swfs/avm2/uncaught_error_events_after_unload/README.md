An `uncaughtError` thrown by a movie loaded into a Loader that another SWF created still reaches the root's `loaderInfo.uncaughtErrorEvents` after that SWF is unloaded and collected. The expected output follows Adobe's documentation of `UncaughtErrorEvents`; no Flash Player trace was available.
